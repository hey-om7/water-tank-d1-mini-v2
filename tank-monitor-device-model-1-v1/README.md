# Tank Monitor Device Model-1 v1 — firmware starter

Model `TMM1V1`, generated by FirmwareManager on 2026-11-09.
OTA updates and remote logging are already wired up. You write your product
logic in `appSetup()` / `appLoop()` in `tank-monitor-device-model-1-v1.ino`.

## Files

| File | What it does |
| --- | --- |
| `tank-monitor-device-model-1-v1.ino` | `setup()` / `loop()` plumbing plus your app hooks |
| `src/config/globals.h` | Model identity, firmware version, server URLs, MQTT credentials, log defaults |
| `src/logging/custom_mqtt_logging.h` | `LOGE/LOGW/LOGI/LOGD` macros that print to USB serial and send logs to the console over MQTT |
| `src/ota/ota_updates.h` | Checks for updates and installs them (primary server first, then fallback) |
| `src/net/wifi_connect.h` | Connects with saved Wi-Fi, opens a setup portal (`TMM1V1-SETUP`) on first boot, reconnects automatically |

## First flash (USB)

1. Use an ESP32 board package (arduino-esp32 2.0.x or 3.x). You don't need any extra libraries.
2. Under **Tools → Partition Scheme**, pick a scheme that has an OTA slot, for example
   *Minimal SPIFFS (1.9MB APP with OTA)*.
3. Flash the board, then open Serial Monitor at 115200 baud and copy the printed **Wi-Fi MAC**.
4. In FirmwareManager, go to **Devices → Add device**, enter that MAC and choose model `TMM1V1`.
5. Join the `TMM1V1-SETUP` Wi-Fi network from your phone and pick your network.

**No `TMM1V1-SETUP` hotspot?** Check Serial Monitor first:
- `connecting to saved network '…'` means the board still has Wi-Fi credentials from older firmware. A normal flash
  doesn't erase them. Hold **BOOT** while powering on, or flash once with
  *Tools → Erase All Flash Before Sketch Upload → Enabled*.
- No output at all on ESP32-C3/S3: set *Tools → USB CDC On Boot → Enabled*.
- Cheap ESP32-C3 boards (e.g. Super Mini): set `WIFI_TX_POWER_LIMIT 1` in `globals.h`.

## Shipping updates

1. Bump `FW_VERSION` in `src/config/globals.h`, for example `1.0.1`.
2. Use **Sketch → Export Compiled Binary** to get the `.bin`.
3. In FirmwareManager, go to **Firmware → Tank Monitor Device Model-1 v1 → New build** and upload it with the **same** version.
4. Devices install it on their next check: at boot, and then every `OTA_CHECK_INTERVAL_MS`.

## Logging levels

Logs reach the console only for the levels you enable. Set them in
**Devices → (device) → Logging**. The device stores the setting and confirms it,
and drops lines for disabled levels before formatting them. DEBUG is never sent
unless you tick it. On first boot the defaults are error + warn + info for the
console and every level for USB serial (see `LOG_*_LEVELS_DEFAULT`).

## Remote restart

Open **Devices**, pick the device, then **Overview → Restart device**. This works while the device is online over MQTT.
The console sends a one-shot restart command, which is never stored, so it can't fire again when the device reconnects.
The device runs `appBeforeRestart()`, sends its pending logs, and then reboots.

## Security

`globals.h` contains the shared MQTT password for this server. Keep this
project out of public repositories.
